REDMAX SOLUTIONS WEBSITE
========================

Pages included:
- index.html       Home
- about.html       About Us
- services.html    Services
- products.html    Products
- contacts.html    Contacts
- quotes.html      Request a Quote

How to view:
1. Extract the ZIP folder.
2. Keep the images folder and styles.css in the same folder as the HTML files.
3. Double-click index.html to open the website in a browser.

The design follows the supplied Redmax reference screenshots: orange brand banner,
dark navy navigation, red accents, white background and product image gallery.

Images:
The images folder contains separate cropped image assets taken from the two
reference screenshots. Replace these with original, high-resolution product
photographs and a transparent logo before publishing for best quality.

Note:
The contact details shown were read from the supplied screenshot and should be
verified before the site is published. Quote/contact forms use mailto and open
the visitor's email application; they are not connected to a server.
